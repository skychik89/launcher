— установка

Четыре шага — и ты в игре

  1. 1
    Скачай установщик

    Кнопка «Скачать для Windows» наверху. Файл один — без рекламы и «помощников».

  2. 2
    Проверь файл (по желанию)

    Перетащи его в блок «Проверка файла» ниже — сайт сравнит отпечаток SHA-256 с официальным, прямо в браузере.

  3. 3
    Запусти и выбери папку

    Если Windows покажет синее окно SmartScreen — нажми «Подробнее» → «Выполнить в любом случае»: так бывает с каждым новым установщиком без платной подписи.

  4. 4
    Введи ник и играй

    Лаунчер сам скачает нужную Java и версию игры. Есть другой лаунчер? Нажми «переезд» — миры и сборки перенесутся.

Отпечаток файла SHA-256 —

Проверить у себя: certutil -hashfile NEELUX-Launcher-Setup.exe SHA256

Лаунчер не собирает данные и не просит пароль от Microsoft: игра запускается по нику. Ключи ИИ (если подключишь свои) хранятся на твоём ПК в зашифрованном виде.
